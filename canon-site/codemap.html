About the Codemap

This map is generated from the Canon source tree using JordanCoin/codemap — an LLM-oriented codebase analysis tool that produces structured documentation from any repository.

🗺️
LLM Navigation
Codemap produces 7 structured documents (STACK, ARCHITECTURE, CONVENTIONS…) that give LLMs precise, targeted context — so they navigate large codebases faster and with fewer hallucinations.
ARCHITECTURE.md
⚡
Parallel Analysis
Four specialised agents run in parallel — tech, architecture, quality, and concerns — each writing their own document directly, then returning a brief confirmation. Fast, focused, no context bleed.

Always Up-to-date
Run /codemap after any significant change to refresh the map. Canon's map lives in .planning/codebase/ and is committed alongside the code.
